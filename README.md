badbulbs is a simple After Effects ScriptUI panel that applies realistic flickering-light expressions to the Opacity of selected layers.
Choose from 9 flicker styles, adjust speed, add startup flicker, or remove all expressions with one click.

Installation

Place the .jsx file in:
Documents/Adobe/After Effects <version>/Scripts/ScriptUI Panels/

Restart After Effects.

Open it via Window → badbulbs by frietjewaterfiets.
